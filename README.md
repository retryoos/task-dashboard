# Aegis Defense Systems: Task Management Dashboard

A responsive task management web app for a fictional defense contractor,
built for ITC 4214 Internet Programming.

## Built with

- HTML5 and semantic markup
- Custom CSS with design tokens (light and dark themes)
- Vanilla JavaScript and jQuery for the DOM work
- Bootstrap 5 (via CDN) for layout and components

## Pages

- `index.html` Home
- `tasks.html` Task board
- `about.html` About and team
- `contact.html` Contact
- `capabilities.html` Capabilities

## Running it

Open `index.html` in any modern browser, or serve the folder with a static
server (for example the VS Code Live Server extension).
